# みんなの写真（結婚式後の写真共有）

結婚式後バージョンの **`/photos` ページ**で、ゲストが当日の写真を投稿・閲覧・ダウンロードできます（トップページには誘導ボタンと、写真が流れる装飾セクションのみ）。保存先は Google Drive です。ギャラリーは最初36枚まで表示し「もっと見る」で追加表示します。

## 仕組み

- **`GET /api/photos`** — 共有フォルダ内の画像一覧を返す（新しい順・最大1000枚）
- **`POST /api/photos`** — `multipart/form-data` で画像をアップロード（`uploaderName` 任意 + `photo` ファイル、1リクエスト最大10枚・各15MBまで）
- **`GET /api/photos/zip`** — 全写真を 1 つの ZIP（無圧縮 store）にまとめてストリーミング返却。「まとめてダウンロード」はこれを使う（Drive のフォルダ画面は開かない）。ファイル名は `連番_投稿者名.jpg`
- 認証は RSVP と同じ（`.env` の `GOOGLE_DRIVE_OAUTH_*` があればユーザーの Drive、なければサービスアカウント）。**追加の設定は不要**です。

## 保存先フォルダ

1. `.env` に `GOOGLE_DRIVE_PHOTOS_FOLDER_ID` があればそのフォルダ
2. なければ `GOOGLE_DRIVE_RSVP_FOLDER_ID` の直下に **「みんなの写真」** フォルダを自動作成して使用

## 公開範囲（重要）

- アップロードされた各写真には **「リンクを知っている全員が閲覧可」** の権限が付きます（サムネイル表示・ダウンロードのため）
- フォルダ本体は共有しません（一括ダウンロードは `/api/photos/zip` がサーバー側で生成）
- サイト URL を知っている人なら誰でも投稿・閲覧できます。公開をやめたいときは Drive で各ファイルの共有を解除してください

## クライアント側の挙動

- 画像は送信前にブラウザ側で **長辺 2560px / JPEG 品質 0.85** に縮小されます（Vercel のリクエスト上限 約4.5MB 対策 + 通信量削減）。2MB 以下の JPEG/PNG/WebP はそのまま送信
- 1枚ずつ順番にアップロードし、進捗バーを表示します
- 投稿者名は `localStorage` に保存され、次回から自動入力されます

## 表示 URL について

- サムネイル: `https://lh3.googleusercontent.com/d/<fileId>=w640`
- 拡大表示: 同 `=w1920`
- ダウンロード: `https://drive.google.com/uc?export=download&id=<fileId>`

いずれも「リンクを知っている全員が閲覧可」の権限が前提です。
